# Domain docs

This repo is **single-context**.

- `CONTEXT.md` at the repo root is the domain glossary. It is a glossary only — no
  specification, no implementation detail.
- `docs/adr/` holds architecture decision records, numbered from `0001`.

Read both before starting work in this repo. Use the glossary's vocabulary in issue
titles, commit messages, code identifiers and UI copy. Respect the ADRs, or write a
new one superseding the old.
