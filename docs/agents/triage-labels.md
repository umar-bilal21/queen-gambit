# Triage labels

The five canonical triage roles, using the default label strings.

| Role | Label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | Not yet assessed. |
| Needs info | `needs-info` | Blocked on information only a human can supply. |
| Ready for agent | `ready-for-agent` | Fully specified; an agent can pick it up unattended. |
| Ready for human | `ready-for-human` | Needs a human decision, credential, or judgement call. |
| Won't fix | `wontfix` | Deliberately not doing this. |
